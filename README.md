# tricontrol

The purpose of this project is to use a Chromium-based web browser (e.g. Chrome, Edge or Opera) to receive IMU data from Triki controller using BLE and send it to another application in the form of the OSC messages.

## Development

Start the local development environment:

```
npm run dev
```

Once started navigate to the app at [`http://localhost:5173`](http://localhost:5173).
